# 플랜두씨 다이어리

강의실과 집에서 Codex Cloud로 이어서 작업하기 위한 프로젝트입니다.

현재 앱 코드, 제품 요구사항, 기술 스택은 아직 정해지지 않았습니다.

## 작업 이어가기

동일한 ChatGPT 계정으로 로그인하고 Cloud 환경에서 이 저장소를 선택한 뒤 진행 중인 클라우드 채팅을 열어 이어갑니다. 새로운 작업에서는 AGENTS.md와 PROJECT_STATUS.md를 먼저 읽습니다. 다른 작업에서 사용할 변경은 커밋하고 저장소에 반영합니다.

## 환경 준비

현재 설치할 의존성이나 실행할 테스트는 없습니다. 설치 스크립트, 환경 변수, 네트워크 비밀값은 필요하지 않습니다.
