# 실제 5일 관찰과 규칙 변경

관찰 질문은 “할 일을 줄이면 하루 완료율이 높아질까?”로 정했다. 초기 규칙은 “하루에 핵심 할 일을 3개씩 정한다.”이며, 관찰 지표와 단위는 날짜별 할 일 완료율(%)이다.

서로 다른 실제 사용 날짜 5일의 결과를 기록했다. 처음 2일의 결과를 근거로 계획 규칙 한 가지를 변경하고, 이후 3일을 같은 지표·단위·계산식으로 비교했다. 실제 날짜와 확정 시각, 완료/예정 수, 변경한 규칙·이유·변경 시각은 앱의 ‘5일간의 계획 돌아보기’와 전체 내보내기 자료에 저장되어 있다.

기록의 근거는 ‘날짜별 기록과 계산 확인’ 및 ‘계획 방식을 바꾼 기록’ 화면과 전체 내보내기 JSON의 experiment 항목이다. 날짜는 예정표 대신 저장된 실제 날짜를 사용한다. 10월 16~18일의 기존 학습 자료를 이번 실험의 1~3일차로 소급하지 않는다.

계산 정책은 시작 시 고정한 내용을 유지했다. 서울 날짜 기준 당일 마감 할 일 중 같은 소유자의 미삭제 계획에 속한 미삭제 할 일의 완료 수 ÷ 예정 수 × 100을 사용한다. 결과 확정 시점의 상태를 보존한다. 누락은 null이며 0으로 채우지 않는다. 계획 0인 날은 평균에서 제외하고, 중복 날짜는 거절한다. 실제 이상값은 보정하지 않으며, 각 날짜의 원분수로 일별 완료율 평균을 구한 뒤 소수 둘째 자리까지 반올림한다. 주 시작은 일요일이다. 변경 전 2일과 변경 후 3일에 같은 기준을 적용했다.

전체 평균은 일별 완료율의 평균이다. 전체 완료 수를 전체 예정 수로 나눈 비율과는 다를 수 있으므로 합계와 평균을 구분한다.

## 짧은 확인 방법 4줄

1. 결과물: [플랜두씨 다이어리](https://pds-study-planner.bronzeamber32.chatgpt.site/). 새 비로그인 창에서 첫 화면이 로그인 화면으로 열리는지 확인한다.
2. 확인 순서: ① 로그인 전 화면 ② 인증 설명서의 성공·거절 요청 증거 ③ 제출한 실제 5일 기록·규칙 변경·집계 화면을 순서대로 확인한다. 채점자가 제출자 계정에 로그인할 필요는 없다.
3. 통과 근거: 본인 자료 200, 비로그인 401, 타인 자료 404, 무효화된 이전 세션 401의 요청·응답 증거와 실제 5일의 기록, 규칙 변경 순서, 화면과 수동 계산의 일치를 확인한다.
4. 실패 안내: 비로그인은 ‘로그인이 필요합니다.’와 401, 타인 자료는 ‘자료를 찾을 수 없습니다.’와 404로 응답한다. 실험 날짜 중복·규칙 변경 순서 위반은 409로 안내한다.
