# Emil 디자인 적용 기록

## 돌아보기 차트 진입 (2026-10-15)

사용자가 명시적으로 요청한 좌→우 공개 효과를 SVG clip-path 650ms에만 적용했다. 레이아웃과 날짜·컨트롤은 이동하지 않는다. 키보드/모션줄이기는 animation:none, 데이터 갱신에는 replay하지 않고 탭 재진입에만 mount 재생한다. 실제 포인터0.65s 및 Enter 진입 animationnone 확인. 실제 데이터값을 바꾸어 모양을 꾸미지 않았다.

## 실행 기록 달력 (2026-10-14)

| Before | After | Why |
|---|---|---|
| 기록 리스트가 기본 화면 | 월 달력과 날짜 클릭 시 체크 패널 | 날짜를 선택하고 빠르게 상태 변경 |
| 상시 펼친 기록 입력 | 시간·메모는 항목 상세에서 선택 | 기본 화면의 입력 부담 감소 |
| 반복 인터랙션에 장식 전환 | 체크·목록 순서 즉시 유지, 패널만 translateX 220ms | 맥락을 유지하며 불필요한 지연 제한 |
| 독립적인 유리 재질 | 기존 panel 배경과 불투명 차콜 패널 | 사이트 디자인 일관성 |
| 닫기 후 위치 유실 | Escape 및 선택 날짜로 포커스 복귀 | 키보드 사용 흐름 유지 |

키보드/reduced-motion은 패널 애니메이션을 끈다. 실제 브라우저 패널/Escape/폼 연결 및 모바일 크기 넘침을 확인했다. checkbox DB mutation 및 실제 모바일 체감 검증은 이번에 실시하지 않았다.

2026-10-14. 사용자 제공 완성 이미지가 화면 구성의 기준이다. 이미지의 설명 말풍선은 제품 UI에 넣지 않는다. 메인이 구현하고 설계자가 방향을 검토하며 검수자가 독립 코드 검토를 수행했다.

## 실제 사용한 스킬

공식 출처: https://github.com/emilkowalski/skills

현재 Codex 환경에 `emil-design-eng`, `apple-design`, `mobile-native`, `review-animations`를 설치하고 해당 SKILL.md를 읽어 적용했다. 별도 모션 라이브러리는 추가하지 않았다. 설치는 로컬 환경별이므로 다른 컴퓨터/Cloud에서는 공식 저장소의 같은 스킬을 설치하거나 내용을 읽어야 한다. 프로젝트 구현 결과는 app/page.tsx, app/design.css, app/globals.css, app/layout.tsx에 남아 있다.

## 적용과 검토

| Before | After | Why |
|---|---|---|
| 단색 중심 대시보드 | 산 배경, 차콜·민트 카드, 노트 배경 회고 영역 | 사용자 승인 이미지의 분위기와 구성을 반영 |
| 반복 선택에 카드 전환 효과 | 선택·키보드 조작 즉시 반응 | 자주 쓰는 동작의 지연 제거 |
| 동일한 모달 진입 | 포인터는 opacity/scale .98의 200ms 진입, 키보드는 즉시 | 입력 방식에 맞는 피드백 |
| hover 일괄 적용 | 정밀 포인터·hover 지원 환경에서만 적용 | 터치 환경 오작동 방지 |
| 작은 모바일 컨트롤 | 입력 16px, 날짜 이동 44×44px | 입력 가독성과 터치 영역 확보 |
| 전환만 reduced-motion 처리 | 애니메이션·전환·눌림 transform 모두 제거 | 사용자 모션 환경 설정 존중 |
| 모달 제목·복귀 연결 부족 | aria-labelledby 및 닫은 뒤 실행 버튼 포커스 복귀 | 키보드·보조 기술 접근성 |

통계는 실제 데이터로 계산하며 0건 완료율은 0%다. 마감 임박은 선택일 포함 3일 이내 미완료 항목이며 클릭하면 근거 목록을 보여준다. 돌아보기의 과제 필수 지연·막힘·시간 집계와 첫 화면 공개 안내를 유지한다.

## 검증 범위

- 실제 TypeScript 검사와 최종 빌드 통과.
- 브라우저에서 데스크톱 화면과 배경 로딩 확인.
- 390px 화면에서 가로 넘침 없음, 날짜 이동 44×44px, 모달 입력 16px 확인.
- 모달 취소 뒤 새 계획 버튼 포커스 복귀, 키보드 모달 transition 0s 확인. 저장하지 않아 사용자 데이터는 바꾸지 않았다.
- 검수자 모션 코드 판정 Approve. 날짜 이동 너비 보완 의견을 반영했다.
- 실제 휴대전화의 터치/키보드/모션 체감은 아직 확인하지 않았다. 이번 변경은 API·DB 로직을 바꾸지 않았으며 이전 통합 테스트를 이번에 재실행한 것으로 주장하지 않는다.
- 로컬 미리보기만 갱신했다. 배포·공개·원격 소스 동기화 없음.
