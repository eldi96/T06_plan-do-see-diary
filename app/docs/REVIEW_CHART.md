# 돌아보기 차트

현재 구현은 components/monthly-chart.tsx, components/planned-progress-bands.tsx, domain/monthly-progress.ts에 있습니다.

- 선택 월의 모든 날짜를 숫자로 표시하며 X축은 직선입니다. 모바일에서는 차트 내부를 가로로 스크롤합니다.
- 상단 곡선은 날짜별 예정 할 일 수를 월 최대값에 대한 상대 높이로 표시하고 옅은 그라데이션을 채웁니다.
- 하단 막대는 해당 날짜에 배치된 할 일의 현재 완료율(0~100%)입니다. 높이 기준을 분리해 100%여도 곡선과 겹치지 않습니다.
- 예정일은 마감일이며 루틴도 포함합니다. 체크 시각 기준이 아니므로 예정일 변경·완료 취소가 반영됩니다. 과거 스냅샷은 아닙니다.
- 툴팁에서 정확한 예정·완료 개수와 완료율을 확인하고, 날짜 클릭 또는 선택으로 계획별 근거를 엽니다.
- 기존 C28~32의 집계 숫자와 시간 계산은 별도로 유지합니다.
- 돌아보기 진입 시 왼쪽부터 650ms로 나타나며 키보드 입력·동작 줄이기 환경에서는 생략합니다.
