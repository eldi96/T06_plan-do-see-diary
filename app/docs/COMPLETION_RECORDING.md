# 완료 체크의 실행 기록 연결

작성: 메인 구현, 설계자 저장설계검토, 검수자 독립정적검토. 2026-10-15.

미완료 항목을 체크하면 실제 시간 입력창이 열린다. 분량을 선택하거나 직접 입력하고 실제 종료시각을 확인한 뒤 저장한다. 입력한 소요시간으로 시작시각을 계산하고 서버에서 시작/종료/초단위 실제시간을 검증한다. 활동은 '진행', 내용은 기존 할 일 제목으로 요약하며 막힘 이유는 선택입력이다. 학습 경험이나 시간을 추정하여 저장하지 않는다.

`POST /api/diary`의 `action=complete,kind=task,id,version,requestId,execution`은 task 완료상태·주기, execution, completion, history, 요청응답을 같은 D1 batch로 저장한다. 같은 키의 재시도는 같은 executionId를 반환한다. 다른 키로 같은버전을 동시에 완료하면 한 요청만 성공한다. 부모계획과 task버전 guard가 실패하면 전체 rollback한다. 이미 완료 상태인 task는 새 complete를 거절한다.

취소는 저장하지 않는다. 완료 취소는 실행기록을 지우지 않으며 이후 다시완료하면 별도 활동기록을 남긴다. 기존 완료/0분기록은 자동변환하지 않고 기존 상세에서 실제자료로 수정한다. legacy toggle API는 호환성을 위해 유지한다.

검증: TypeScript/build, 기존격리 API38개 및 신규 complete 전용검사, 격리브라우저15분 완료/기록생성확인. 실제 사용자 DB로 시험기록을 저장하지 않았다. 운영배포검증은 별도다.
